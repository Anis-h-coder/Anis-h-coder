<sub>A snake eats through your contribution graph — animates automatically once set up.</sub>

<details>
<summary><b>⚙️ 2-minute setup (click to expand)</b></summary>
<br>

In your `Anis-h-coder/Anis-h-coder` profile repo, add `.github/workflows/snake.yml`:

```yaml
name: Generate Snake
on:
  schedule:
    - cron: "0 */6 * * *"
  workflow_dispatch:
  push:
    branches: [ main ]

jobs:
  generate:
    runs-on: ubuntu-latest
    permissions:
      contents: write
    steps:
      - uses: Platane/snk@v3
        id: snake
        with:
          github_user_name: ${{ github.repository_owner }}
          outputs: dist/github-contribution-grid-snake.svg
      - uses: crazy-max/ghaction-github-pages@v4
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

Push it, run it once manually (`Actions → Generate Snake → Run workflow`), and the image above lights up.
