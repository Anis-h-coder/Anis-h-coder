# GitHub Profile Setup

1. Create a public repository named exactly `Anis-h-coder`.
2. Upload `README.md`.
3. Upload the `assets` folder containing `profile.png`.
4. GitHub will automatically show this README on your profile because the repository name matches your username.
5. The profile image is referenced as `./assets/profile.png`, so it will work after both files are pushed.
